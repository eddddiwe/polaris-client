Everything you need

A modern Minecraft launcher built for performance and control.

⚡

Hardware-Aware Performance

Auto-detects your CPU, RAM, and GPU. Applies optimized JVM flags, memory allocation, and video settings tailored to your machine.

🧩

Mods & Modpacks

Browse Modrinth, install mods with one click, import .mrpack files, and manage your instances effortlessly.

🎮

Server Management

Launch dedicated servers, manage server.properties, send console commands, and monitor performance.

🎨

Local Cosmetics

Badges, capes, and shards — all stored locally. No backend, no tracking, no accounts needed.

🔄

Auto-Update

Downloads and installs updates automatically. Always stay on the latest version without manual downloads.

🔐

Microsoft Login

Secure device-code OAuth flow. Tokens stored locally, never sent to third parties.

📊

Performance Profiles

Competitive, Balanced, or Quality — each with tuned render distance, simulation distance, and JVM args.

🗂️

Instance Management

Multiple instances with separate worlds, mods, and settings. Fabric and Vanilla support.
