# 0.4.2 security review record

This release followed the gate in [../CODE_REVIEW.md](../CODE_REVIEW.md).

## Reviewers

- Reviewer A — correctness: independent subagent, `beam-free`.
- Reviewer B — security: independent subagent, `flint-40b-free`.
- Code arena — two fresh independent reviewers, `nemotron-3.5-super-vl-free` and `beam-free`, same rubric.

Paid reviewer models were unavailable (insufficient account funds). The free-model limitation is recorded here rather than silently skipping the arena.

## Blocking findings and fixes

1. **High — plaintext friend secret fallback.** If OS encryption failed, `AccountStore` could write the 256-bit API credential as `plain:`. Fixed by `encodeSecret()` and fail-closed save behavior; the secret is not persisted or used when encryption is unavailable. Regression test added.
2. **High — zip limits applied only to declared sizes.** `readZipEntry`/`readZipText` now enforce the limit on the decompressed bytes as well as the declared size. Added tests for lying sizes and empty/`.` path segments.
3. **High — updater helper hash/handle race.** The helper now opens a `FileShare.Read` handle before hashing and holds it through `Start-Process`, so the verified installer cannot be replaced before execution.
4. **Medium — macOS Intel signature.** `resetAdHocDarwinSignature` is now set for every macOS build after fuse flipping.
5. **Medium — offline friend flows.** Friend removal and presence degrade locally when registration is offline; server rejections still surface.
6. **Low — per-account cache leak.** `FriendStore` is scoped by friend code so an offline account cannot see another account's cached friends.

## Residual notes

- Worker rate limiting is per isolate and keyed by `CF-Connecting-IP`; it is not a global counter. A shared rate-limit binding or Durable Object is the next step if abuse appears.
- Legacy access/refresh token persistence still has the documented `plain:` fallback when `safeStorage` is unavailable. Friend secrets no longer use that fallback.
- The Windows installer remains unsigned. The updater now requires the GitHub release asset digest, re-verifies it in the helper and pins the file while it runs; code signing is still recommended before wide distribution.
- Verified for this release: typecheck, 52 tests, production build, Windows NSIS build, fuse readback, installed 0.4.2 launch, encrypted `friendSecret` in `accounts.json`, and live Worker auth smoke tests.
