01 · Performance

Tuned before the first frame.

Most launchers ask how much RAM you have. Polaris also asks what your GPU is, how many threads you have, and which Java you actually installed. Then it writes a plan you can read, edit, and undo.

Tier 01

  • Frame pacing first
  • All three profiles

            02 · The stack
            
    One launcher. The whole stack.
    
            
    
              Install the game, curate the mods, tune the flags, and start the server from the
              same place. Polaris is opinionated where defaults are bad and transparent
              everywhere else.
            
    
          
    

          
    
            
    
              
                
              
              
    Hardware scan, not guesswork
    
              
    
                One local GPU query, thread count, system RAM, and the Java runtimes it can find.
                Polaris classifies the machine, sizes the heap, and keeps every decision visible.
              
    
              
    
                entry
                
                
                
                
                enthusiast
              
    
            
    

            
    
              
                
              
              
    Verified installs
    
              
    
                Tracked jars are pinned by version and sha1. One batch hash request tells Polaris
                what drifted before it touches anything.
              
    
              
    
                sha1 pinned
                1 batch query
              
    
            
    

            
    
              
                
              
              
    Packs that know your GPU
    
              
    
                Client and server targets, plus hardware gates. A mod that needs NVIDIA is skipped
                with a reason instead of quietly breaking the pack.
              
    
              
    
                requires: nvidia
                client | server
              
    
            
    

            
    
              
                
              
              
    A server is another instance
    
              
    
                Create a Fabric server with its own port, mods, EULA gate, and console. Stop it
                gracefully by writing to stdin; the log streams into the same window.

                Aikar G1, low-latency G1, or Generational ZGC. The generational flag only appears
                on Java 21–22, where it is actually accepted.

              Servers
              
    Your world. Your machine.
    
              
    
                A dedicated server is just another instance in the sidebar. Same cards, same mods,
                same console. No separate launcher, no remote panel you did not ask for.
              
    
              
      
                
    • 
                  
                  Server-targeted packs, so client-only mods never end up in the server folder.
                
      • 
                
    • 
                  
                  Explicit EULA gate, custom port, and a graceful stop written to
                  stdin instead of killing the process.
                
      • 
                
    •

      • 
                
    •

      • 
              
    
              
    
                
                Servers run locally for now. There is no remote panel or multi-user management.

            08 · FAQ
            
    The honest answers.
    
            
    
              What Polaris does, what it deliberately does not do, and which parts are still
              roadmap. If a feature needs a server or a mod, the page says so.
            
    
            
              Install it or build it
              
            
          
    
          
    
            
    
              Is Polaris a hacked client?
              
    
                No. Polaris does not inject modules into Minecraft, alter network packets, or ship
                combat automation. It manages instances, downloads files, writes vanilla options,
                and launches Fabric when you ask it to. The performance work is standard mods and
                JVM tuning.
              
    
            
    
            
    
              Which versions and loaders are supported?
              
    
                Vanilla launching works across the versions Polaris installs. Mods, curated packs,
                and .mrpack imports are Fabric-only. Quilt, Forge, and NeoForge packs
                are rejected rather than half-installed. Fabric must support the selected Minecraft
                version before a fabric instance can be created.
              
    
            
    
            
    
              Does it phone home?
              
    
                There is no telemetry and no analytics endpoint. Polaris talks to Mojang, Fabric
                meta, and Modrinth only when it needs version data, files, or updates. Microsoft
                sign-in is the device-code flow with an Azure client ID you supply; offline accounts
                need no network at all.
              
    
            
    
            
    
              How do shards work?
              
    
                You start with 900 shards and earn 40 for every tracked hour of playtime. The
                balance, owned items, and equipped badge and cape are stored in your local settings.
                There is no checkout and no way to buy shards in this build.
              
    
            
    
            
    
              Will other players see my badge or cape in-game?
              
    
                Not yet. Cosmetics show next to your account inside Polaris — on Home, in Settings,
                and in the account switcher. In-game visibility for other players requires a
                companion mod or server relay, which is not shipped in 0.3.0. The website and the
                store label it as roadmap instead of pretending it already works.
              
    
            
    
            
    
              Can Polaris host a server?
              
    
                Yes, as a local dedicated-server instance. It handles the EULA gate, port, server
                mods, console, and a graceful stop. It is not a remote panel: there is no multi-user
                management, scheduled restart, or public hosting service built in.
              
    
            
    
            
    
              Does Microsoft sign-in work?
              
    
                The flow is implemented, but it needs your own Azure public-client ID. Without one,
                use an offline account. Polaris never ships or borrows someone else's OAuth client,
                and unapproved apps can receive a 403 from Minecraft Services.
              
    
            
    
            
    
              How do I install the Windows build?
              
    
                Download Polaris-Setup.exe from this page and run it. The NSIS installer is per-user
                and lets you choose a folder, so it does not need administrator rights. If SmartScreen
                warns because the build is unsigned, verify the SHA-256 shown on this page, then choose
                More info and Run anyway. Uninstall it from Settings → Apps.
              
    
            
    
            
    
              Why is the build unsigned?
              
    
                The Windows installer and portable build are produced locally and are not code-signed,
                so SmartScreen may warn. The SHA-256 is published in downloads/latest.json; verify the
                file with Get-FileHash .\Polaris-Setup.exe -Algorithm SHA256 before running
                it. Sign with a certificate you control before distributing it more widely.
              
    
            
    
            
    
              Is there a macOS or Linux build?
              
    
                Windows 10/11 is the primary target. Linux packaging is available from source:
                npm run dist:linux on Linux or WSL2 produces an AppImage, and CI is
                configured to build it on Ubuntu. Java and GPU discovery now have Linux paths, but
                Linux runtime support is still experimental. macOS is not tested. Server instances
                are managed from the same app.
